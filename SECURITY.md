# Security Policy

## Scope

Shopping Config Assistant is a Chrome extension that assists with selected Apple Online Store configuration and checkout-preparation steps.

The extension is designed so that payment selection, payment authentication and final order submission remain manual.

## Sensitive information

Please **do not** submit any of the following in a public GitHub issue:

- passwords;
- one-time verification codes;
- authentication tokens;
- card or bank details;
- full home addresses;
- private email addresses or phone numbers;
- screenshots containing sensitive checkout information.

Before sharing screenshots or logs, redact personal and payment-related information.

## Intended security boundaries

The extension is not intended to:

- collect or store payment-card details;
- collect passwords or verification codes;
- bypass CAPTCHAs or account-security controls;
- execute remote JavaScript or WebAssembly;
- submit a final order automatically.

## Reporting

For ordinary functional problems, use the repository support information.

For a potentially security-sensitive issue, avoid publishing exploit details or personal data in a public issue. Use the developer contact method provided on the Chrome Web Store listing.

## Supported version

Security and support documentation currently applies to extension version **0.3.1 Beta** and later versions unless a release notes otherwise.
