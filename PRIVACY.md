# Privacy Policy / 隐私政策

**Shopping Config Assistant / 购物配置助手（Beta）**  
**Last updated / 最后更新：21 September 2026 / 2026年9月21日**

This Privacy Policy explains how the Shopping Config Assistant Chrome extension handles information.  
本隐私政策说明“购物配置助手（Beta）”Chrome 扩展如何处理用户信息。

## 1. Purpose / 用途

Shopping Config Assistant is designed to help users configure a product and prepare checkout information on supported Apple Online Store pages in Australia and China Mainland.

购物配置助手用于在受支持的 Apple 澳大利亚和中国大陆在线商店页面中，根据用户预先设置的信息辅助完成商品选配、购物袋检查、配送或自取选择，以及联系人/配送信息填写。

The extension is designed to stop at the payment-method stage. Payment-method selection, payment authentication and final order submission must be completed by the user.

本扩展会在付款方式阶段停止。付款方式选择、支付验证以及最终订单提交均由用户本人完成。

## 2. Information handled by the extension / 本扩展处理的信息

Depending on what the user chooses to save, the extension may handle:

- first name and last name / 姓名；
- email address / 电子邮箱地址；
- telephone number / 电话号码；
- postal code / 邮政编码；
- street address and optional address line 2 / 街道地址及可选的地址补充信息；
- city, suburb, district, state or province / 城市、Suburb、区县、州或省；
- selected product region, model, colour and storage capacity / 商品地区、型号、颜色和存储容量；
- delivery or Apple Store pickup preference / 配送或 Apple Store 自取偏好；
- selected Apple Store pickup location / 用户选择的 Apple Store 自取门店；
- limited webpage content necessary to identify supported product, bag and checkout controls on Apple Store pages / 为识别 Apple 商店页面中的商品、购物袋及结账控件而需要读取的有限网页内容。

## 3. How information is used / 信息用途

The information above is used only to provide the extension's user-facing shopping-assistance functionality, including:

- saving the user's selected configuration;
- querying a nearby Apple Store list based on the user's entered postal code;
- selecting supported product options;
- checking the shopping bag;
- choosing delivery or pickup;
- filling contact or delivery fields on supported Apple checkout pages;
- maintaining the temporary state of an active assisted-shopping session.

上述信息仅用于实现本扩展向用户提供的购物辅助功能，包括保存商品配置、按邮编查询附近 Apple Store、辅助选择商品、核对购物袋、选择配送或自取、填写联系人或配送信息，以及维护当前辅助流程的临时状态。

The extension does not use this information for advertising, profiling, credit decisions or unrelated purposes.

本扩展不会将上述信息用于广告、用户画像、信用评估或与扩展核心功能无关的用途。

## 4. Storage / 数据存储

User-saved configuration and contact information may be stored in Chrome extension local storage on the user's device. The developer does not operate a backend server for collecting or storing this information.

用户主动保存的商品配置和联系人信息可能存储于用户设备上的 Chrome 扩展本地存储中。开发者不运营用于收集或保存这些信息的后台服务器。

Temporary assisted-shopping run state is stored using Chrome extension session storage and is used only for the active workflow.

辅助购买流程中的临时运行状态使用 Chrome 扩展会话存储，仅用于当前运行流程。

Users can remove saved settings from the extension's settings page. Uninstalling the extension also removes extension-managed browser storage according to Chrome's normal extension behavior.

用户可以在扩展设置页面中清除已保存的信息。卸载扩展也会按照 Chrome 的正常扩展机制移除该扩展管理的浏览器存储。

## 5. Transmission to Apple / 向 Apple 提交信息

When the user intentionally starts the assisted-shopping flow, the extension may place the user's saved contact or delivery information into forms on Apple-operated websites. Once information is entered into Apple webpages, Apple's own privacy policy and terms govern Apple's processing of that information.

当用户主动启动辅助购买流程时，本扩展可能会把用户保存的联系人或配送信息填写到 Apple 运营的网站表单中。信息进入 Apple 网页后，Apple 对这些信息的处理受 Apple 自身隐私政策和相关条款约束。

The extension may also send the selected product identifier and the postal code entered for pickup lookup to an Apple-operated store-availability endpoint in order to display nearby pickup locations.

为查询附近自取门店，本扩展还可能把所选商品标识以及用户输入的查询邮编发送至 Apple 官方门店查询接口。

## 6. Information not collected or processed by the extension / 本扩展不会收集或处理的信息

The extension is not designed to collect, store or transmit:

- credit or debit card numbers;
- bank-account details;
- Apple Pay credentials;
- account passwords;
- PINs;
- one-time passwords or verification codes;
- security-question answers;
- authentication tokens intentionally extracted from user accounts.

本扩展不会主动收集、保存或传输银行卡号、银行账户信息、Apple Pay 凭据、账户密码、PIN、一次性密码或验证码、安全问题答案，或主动从用户账户中提取的身份验证令牌。

If a login, payment authentication, CAPTCHA or other security check is required, the user must complete it manually.

如页面要求登录、支付验证、CAPTCHA 或其他安全验证，必须由用户本人手动完成。

## 7. Payment and final ordering / 付款与最终下单

The extension is designed to stop when it detects the payment-method stage. It does not select a payment method, enter card details, trigger Apple Pay, or submit the final order on the user's behalf.

本扩展设计为在识别到付款方式阶段时停止，不会代替用户选择付款方式、填写银行卡资料、触发 Apple Pay 或提交最终订单。

## 8. Third parties, advertising and analytics / 第三方、广告与分析

The extension does not include third-party advertising and does not use third-party analytics or behavioral tracking services.

本扩展不包含第三方广告，也不使用第三方用户行为分析或追踪服务。

The developer does not sell user personal information.

开发者不会出售用户个人信息。

## 9. Website access / 网站访问范围

The extension is intended to operate only on supported Apple Store pages and Apple-operated endpoints required for the declared functionality. It is not intended to monitor unrelated websites or build a browsing-history profile.

本扩展仅用于访问实现所声明功能所需的受支持 Apple Store 页面和 Apple 官方接口，不用于监控无关网站或建立用户浏览历史画像。

## 10. Data security / 数据安全

The extension limits its declared permissions to those required for its functionality. Users should not save payment-card information, passwords, verification codes or other credentials in extension fields.

本扩展尽量将声明的权限限制在实现功能所需的范围内。用户不应在扩展字段中保存银行卡信息、密码、验证码或其他认证凭据。

Chrome local extension storage should not be treated as an encrypted password vault. Users who share a computer or Chrome profile should consider this before saving contact or address information.

Chrome 扩展本地存储不应被视为加密密码保险库。与他人共用电脑或 Chrome 配置文件的用户，在保存联系人或地址信息前应考虑这一点。

## 11. Children's privacy / 未成年人隐私

The extension is not specifically directed at children and is intended for users who can lawfully use the relevant online shopping services.

本扩展并非专门面向儿童，适用于能够依法使用相关在线购物服务的用户。

## 12. Changes to this policy / 隐私政策变更

This policy may be updated if the extension's functionality or data handling changes. The latest public version will be maintained in this repository.

如果扩展功能或数据处理方式发生变化，本隐私政策可能相应更新。最新公开版本将维护在本仓库中。

购物配置助手为独立项目，与 Apple Inc. 不存在隶属、认可、赞助或运营关系。
