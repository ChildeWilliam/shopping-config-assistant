隐私政策 / Privacy Policy

购物配置助手（Beta） / Shopping Config Assistant
最后更新 / Last updated: 2026年9月21日 / 21 September 2026

1. 用途 / Purpose

购物配置助手用于在受支持的 Apple 澳大利亚和中国大陆在线商店页面中，根据用户预先设置的信息辅助完成商品选配、购物袋检查、配送或自取选择，以及联系人/配送信息填写。

Shopping Config Assistant helps users configure a product and prepare checkout information on supported Apple Online Store pages in Australia and China Mainland.

本扩展会在付款方式阶段停止。付款方式选择、支付验证以及最终订单提交均由用户本人完成。 The extension is designed to stop at the payment-method stage; payment selection, authentication and final order submission remain manual.

2. 本扩展处理的信息 / Information handled

  • 姓名 / first and last name
  • 电子邮箱地址 / email address
  • 电话号码 / telephone number
  • 邮政编码 / postal code
  • 街道地址及地址补充信息 / street address and optional address line 2
  • 城市、Suburb、区县、州或省 / city, suburb, district, state or province
  • 商品地区、型号、颜色和存储容量 / selected region, model, colour and storage capacity
  • 配送或 Apple Store 自取偏好 / delivery or Apple Store pickup preference
  • 用户选择的 Apple Store 自取门店 / selected pickup store
  • 为识别 Apple 商店商品、购物袋及结账控件而需要读取的有限网页内容 / limited webpage content required to identify supported Apple Store product, bag and checkout controls

3. 信息用途 / How information is used

上述信息仅用于实现本扩展的核心购物辅助功能，包括保存配置、按邮编查询附近 Apple Store、辅助选择商品、核对购物袋、选择配送或自取、填写联系人或配送信息，以及维护当前流程的临时状态。

The information is used only to provide the extension's shopping-assistance functionality. It is not used for advertising, profiling, credit decisions or unrelated purposes.

4. 数据存储 / Storage

用户主动保存的商品配置和联系人信息可能存储于用户设备上的 Chrome 扩展本地存储中。开发者不运营用于收集或保存这些信息的后台服务器。

User-saved configuration and contact information may be stored in Chrome extension local storage on the user's device. The developer does not operate a backend server for collecting or storing this information.

辅助购买流程中的临时运行状态使用 Chrome 扩展会话存储。用户可以通过扩展设置页面清除已保存的信息。

5. 向 Apple 提交信息 / Transmission to Apple

当用户主动启动辅助购买流程时，本扩展可能会把用户保存的联系人或配送信息填写到 Apple 运营的网站表单中。信息进入 Apple 网页后，Apple 对这些信息的处理受 Apple 自身隐私政策和相关条款约束。

The extension may also send the selected product identifier and a postal code entered for pickup lookup to an Apple-operated store-availability endpoint in order to display nearby pickup locations.

6. 不收集或处理的敏感信息 / Sensitive information not collected

本扩展不会主动收集、保存或传输银行卡号、银行账户信息、Apple Pay 凭据、账户密码、PIN、一次性密码或验证码、安全问题答案，或主动从用户账户中提取的身份验证令牌。

The extension is not designed to collect, store or transmit payment-card details, bank-account details, passwords, PINs, one-time verification codes or intentionally extracted authentication credentials.

7. 付款与最终下单 / Payment and final ordering

本扩展设计为在识别到付款方式阶段时停止，不会代替用户选择付款方式、填写银行卡资料、触发 Apple Pay 或提交最终订单。

If login, payment authentication, CAPTCHA or another security check is required, the user must complete it manually.

8. 第三方、广告与分析 / Third parties, advertising and analytics

本扩展不包含第三方广告，也不使用第三方用户行为分析或追踪服务。开发者不会出售用户个人信息。

The extension does not include third-party advertising or third-party behavioral analytics, and the developer does not sell user personal information.

9. 网站访问范围 / Website access

本扩展仅用于访问实现所声明功能所需的受支持 Apple Store 页面和 Apple 官方接口，不用于监控无关网站或建立用户浏览历史画像。

10. 数据安全 / Data security

Chrome 扩展本地存储不应被视为加密密码保险库。用户不应在扩展字段中保存银行卡信息、密码、验证码或其他认证凭据。与他人共用电脑或 Chrome 配置文件的用户，在保存联系人或地址信息前应考虑这一点。

11. 未成年人隐私 / Children's privacy

本扩展并非专门面向儿童，适用于能够依法使用相关在线购物服务的用户。

12. 政策变更 / Changes

如果扩展功能或数据处理方式发生变化，本隐私政策可能相应更新。最新版本将维护在本公开仓库中。

13. 联系方式 / Contact

如对隐私或产品支持有疑问，请访问 项目公开支持仓库，或通过 Chrome Web Store 商品页面中公布的开发者联系方式联系开发者。

14. 独立性声明 / Independence notice

购物配置助手为独立项目，与 Apple Inc. 不存在隶属、认可、赞助或运营关系。 Shopping Config Assistant is an independent project and is not affiliated with, endorsed by, sponsored by, or operated by Apple Inc.
