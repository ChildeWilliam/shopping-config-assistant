购物配置助手（Beta）

Shopping Config Assistant · Chrome Extension · Version 0.3.1 Beta

购物配置助手用于在受支持的 Apple Online Store 页面中辅助商品选配、购物袋核对、配送/自取选择以及联系人和配送信息填写。

Shopping Config Assistant helps users prepare selected product and checkout information on supported Apple Online Store pages.

付款由用户本人完成。 扩展会在付款方式阶段停止，不会填写银行卡资料、选择付款方式或自动提交最终订单。
